# RazeKit DEV

Standalone RazeKit DEV foundation. Phase 1 task creation and Phase 2 Agent Manager are being implemented here.

## Phase 2
App/Website tasks route to Niomi; Game tasks route to Konami. Each task gets one isolated agent instance with its own workspace, worker, tool manifest, state and budget ceiling.

This repository currently contains the orchestration prototype; real containers, model sessions, external credentials and production billing/runtime adapters are future execution-layer work.
